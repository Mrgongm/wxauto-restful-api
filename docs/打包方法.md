\1. 创建并使用虚拟环境

 python -m venv myenv

.\myenv\Scripts\activate





\2. 安装pyinstaller以及你项目的所有依赖库

pip install pyinstaller

pip install wxautox4

pip install ... 你的项目依赖库



\3. 将app.spec文件放入打包目录，并修改信息



编辑器打开该文件，修改第8、9行信息，保存






\4. 开始打包

pyinstaller app.spec

打包结束后，在新生成的dist文件夹中找到你的exe执行程序
